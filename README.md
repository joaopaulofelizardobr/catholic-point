# Projeto Integrador Frontend

Catholic Point
O Catholic Point é um site dedicado à divulgação da história dos santos e das devoções marianas da Igreja Católica. Seu objetivo é reunir informações históricas, biográficas e litúrgicas em um ambiente organizado e de fácil consulta.

O projeto foi desenvolvido como parte do Projeto Integrador do curso de Ciência da Computação, com foco no desenvolvimento front-end.
Acesso ao site
Catholic Point
Funcionalidades
- Catálogo de santos organizado por períodos históricos: primeiros séculos, medieval, moderno e contemporâneo.
- Catálogo de títulos marianos.
- Consulta ao Santo do Dia com base na data de celebração.
- Exibição de informações biográficas, históricas e litúrgicas.
Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages

O arquivo santos.js armazena os dados dos santos e títulos marianos em arrays de objetos JavaScript. O arquivo santo-do-dia.js é responsável pela consulta das celebrações diárias.
Como executar localmente
Clone o repositório:
git clone https://github.com/joaopaulofelizardobr/projeto-integrador-frontend-joaopaulo.git
cd projeto-integrador-frontend-joaopaulo
Abra a pasta no Visual Studio Code e execute o arquivo index.html utilizando a extensão Live Server.
